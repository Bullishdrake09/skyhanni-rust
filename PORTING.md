# SkyHanni on Horizon

A Horizon native-mod bundle generated by horizon-port from `SkyHanni-9.3.0-mc26.2.jar`. It builds as it is and plays like vanilla: every injection that is on leaves the game unchanged until its `TODO` is filled in. 14 injections are on; 135 are written commented out in `mixins/skyhanni/horizon-mixin.toml`, with why.

## Build it

Horizon's launcher builds a bundle folder itself (it downloads its own Rust the first time):

```bash
horizon-launcher native-build "<this folder>" --trust-native-code
```

Native mods run with your rights and aren't sandboxed: build only code you have read. `cargo test` here runs `runtime.rs`'s own tests without the game.

## Limits

- The mod's own logic that doesn't need the game is translated into `runtime.rs` (`pub mod java`): Translated 5565 of 52627 methods (2 more are done another way in Horizon) and 4306 of 9207 static fields to Rust (26 of those call the game, through Horizon's helpers); 1 of 2 Fabric event handlers. Code that uses Minecraft classes isn't: each helper lists the game calls its Java makes and what they are in Horizon. See `report/translation.md`.
- `BEFORE_CALL`, `AFTER_CALL`, `MODIFY_ARG` and `WRAP_OPERATION` select the called function by name (`selector`), with `require` counted in the target's source. horizon-mixins checks both when it plans: a mismatch fails the build with a message, it never applies silently.
- Raw targets are functions of one Horizon commit (`a46ce6898bd72016e061aaec1afc1375b384deac`): a newer Nightly may move them.
